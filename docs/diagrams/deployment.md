## Миграция на 2 сервера

### Шаги

1. Арендовать сервер B (Ubuntu + Docker)
2. Развернуть llama.cpp на B — та же модель Qwen3-4B
3. Настроить WireGuard VPN между A и B
4. Ограничить доступ — на B порт 8080 только для IP A
5. Изменить MODEL_SERVER_URL в .env на A
6. Перезапустить API: docker compose restart api
7. Проверить smoke + system-health

### Что переносится

| Компонент | Куда |
|-----------|------|
| llama.cpp + модель | на B |
| PostgreSQL | остаётся на A |
| Qdrant | остаётся на A |
| Документы | остаются на A |
| Диалоги, решения, задачи | остаются на A |
| Monitoring | часть на A, часть на B |

### Что НЕ переносится

- Данные (БД, векторы, документы) — всегда на сервере A
- Пользователи и роли — в Laravel, не в NEXUS AI

## Размеры серверов

| A — Platform | 4 | 8 ГБ | 100 ГБ | нет |

## Преимущества 2 серверов

- Независимое масштабирование модели
- Возможность GPU-апгрейда без переезда всей системы
- Изоляция compute от данных
- Возможность A/B тестирования моделей

## Недостатки

- +1 сервер (~500–1000 руб/мес)
- Сетевой канал между A и B
- Дополнительная точка отказа
- Сложнее диагностика
