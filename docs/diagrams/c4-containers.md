| nexus-embeddings | 8001 | 800 МБ |
| nexus-qdrant | 6333 | 270 МБ |
| nexus-postgres | 5432 | 130 МБ |
| nexus-prometheus | 9090 | 154 МБ |
| nexus-grafana | 3000 | 148 МБ |

Итого RAM: ~4.6 ГБ из 16 ГБ.

## Сетевая изоляция

| Порт | Кто видит |
|------|-----------|
| 80 (Nginx) | Публично |
| 3000 (Grafana) | Публично |
| 8000, 8080, 8001, 6333, 5432, 9090 | Внутри Docker-сети |
| 22, 80, 443, 3000 | UFW (наружу) |

## Связи

- Клиент → Nginx → API (8000)
- API → Model (8080) — инференс
- API → Qdrant (6333) — RAG-поиск
- API → Embeddings (8001) — эмбеддинги
- API → PostgreSQL (5432) — метаданные
- Prometheus → все сервисы (scrape `/metrics`)
- Grafana → Prometheus (запросы)
