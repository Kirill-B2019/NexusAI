# Фронтенд NEXUS AI

Пользовательский интерфейс на Laravel 12, Blade и Livewire 3. Alpine.js уже
поставляется вместе с Livewire — не подключайте вторую копию. Авторизация
работает через стандартный веб-сеанс Laravel и Fortify.

## Локальный запуск

1. Откройте папку `frontend/` в PhpStorm. В **Settings → PHP** укажите
   локальный интерпретатор PHP (в текущей установке XAMPP:
   `C:\xampp\php\php.exe`) и Composer PHAR
   (`%LOCALAPPDATA%\Composer\composer.phar`). Если IDE не обнаружила Node.js
   автоматически, задайте путь к установленному Node.js.
2. Если `.env` ещё нет, скопируйте `.env.example` в `.env`. Файл `.env`
   игнорируется Git и должен оставаться локальным. Укажите `APP_URL`, затем
   параметры локальной MySQL: `DB_CONNECTION=mysql`, `DB_HOST`, `DB_PORT`,
   `DB_DATABASE`, `DB_USERNAME` и `DB_PASSWORD`. Сначала создайте базу данных.
   Не помещайте ключи NEXUS AI в настройки браузера.
3. Установите зависимости и примените миграции к локальной базе:

   ```powershell
   composer install
   npm install
   php artisan key:generate
   php artisan migrate --seed
   npm run build
   ```

4. Запустите приложение в терминале PhpStorm:

   ```powershell
   php artisan serve
   ```

   Для разработки стилей запустите `npm run dev` во втором терминале. Откройте
   `http://127.0.0.1:8000`.

## Вход и роли

Публичная регистрация отключена. Для первоначальной настройки администратора
задайте в локальном `.env` переменные `NEXUS_ADMIN_NAME`,
`NEXUS_ADMIN_EMAIL` (адрес для входа) и `NEXUS_ADMIN_PASSWORD` (не менее
16 символов), затем выполните `php artisan migrate --seed`. Сидер создаёт или
обновляет эту учётную запись и назначает ей роль `admin`; при повторном запуске
сида пароль администратора синхронизируется со значением в `.env`.

После 15 минут без реальных действий пользователя интерфейс отправляет запрос
выхода, сервер инвалидирует сеанс, а браузер переходит на главную страницу
(`/`), которая для гостя открывает вход. Таймер учитывает ввод, указатель,
клавиатуру, прокрутку и касания; фоновые запросы и polling его не продлевают.
Сервер независимо проверяет idle-срок на защищённых маршрутах, поэтому
клиентский таймер не является единственной защитой. Если вкладка была
заморожена браузером, истечение проверяется сразу при её возвращении на экран.

На странице **Пользователи** администратор может создать учётную запись и
назначить ей роль `admin`, `user` или `viewer`. Система создаёт случайный
временный пароль и показывает его администратору однократно после создания.
Передайте пароль пользователю безопасным способом; при первом входе ему нужно
задать новый пароль, прежде чем пользоваться остальными разделами.

Доверенный оператор также может изменить роль уже существующего пользователя
командой:

```powershell
php artisan app:assign-user-role you@example.com admin
```

Административный экран и создание пользователей защищены проверкой роли и
разрешением `manage-users`. Публичная регистрация отключена. Разрешения для
проектов уже различают пользователей с правом изменения и пользователей
только для чтения; политики владения будут добавлены вместе с функциями
проектов.

Письма для восстановления пароля отправляются через настроенный почтовый
транспорт Laravel. В локальной конфигурации `MAIL_MAILER=log` ссылка сброса
записывается в `storage/logs/laravel.log`.

Тесты всегда используют отдельную временную SQLite в памяти и не подключаются
к MySQL из `.env`:

```powershell
php artisan test
```

Панель — защищённая основа пользовательского интерфейса. Подключения к
production-сервису NEXUS AI пока нет.
